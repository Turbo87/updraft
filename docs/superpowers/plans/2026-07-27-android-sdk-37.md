# Android SDK 37 Compile Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compile Updraft-owned Android modules against SDK 37 without opting the application into Android 17 runtime behavior.

**Architecture:** The generated application and Updraft mobile plugin move to compile SDK 37 while retaining target SDK 36 and minimum SDK 24. Tauri's Android library remains on compile SDK 36, so CI installs both platform versions and keeps AGP's selected Build Tools 36.0.0.

**Tech Stack:** Android SDK 36 and 37.0, Android Gradle plugin 9.3.1, Gradle 9.6.1, Java 21, Tauri 2.11.

## Global Constraints

- Keep `targetSdk = 36`.
- Keep `minSdk = 24`.
- Keep Android SDK Build Tools 36.0.0.
- Keep Android Gradle plugin 9.3.1, Gradle 9.6.1, Java 21, and NDK 28.1.13356709.
- Do not change AndroidX dependency versions in this branch.
- Retain SDK Platform 36 in CI for Tauri's Android library.
- Add SDK Platform 37.0 in CI for the Updraft application and mobile plugin.
- Treat the existing Tauri legacy-DSL deprecation warnings as an upstream constraint. Do not suppress them or expand this change into an AGP migration.

- [x] **Step 2: Raise the application compile SDK**

In `tauri/gen/android/app/build.gradle.kts`, change only the compile SDK:

```kotlin
android {
    compileSdk = 37
    namespace = "aero.updraft"
    defaultConfig {
        manifestPlaceholders["usesCleartextTraffic"] = "false"
        applicationId = "aero.updraft"
        minSdk = 24

```
