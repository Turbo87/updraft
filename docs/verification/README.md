# Verification Records

Verification records contain dated manual or physical checks that automated
tests cannot prove.

- [Android platform verification](2026-07-26-android-platform.md)
- [Android SPP physical verification](2026-07-27-android-spp.md)
- [Arrival height verification](2026-09-05-arrival-heights.md)

Each record must state the tested behavior, relevant environment, result, and
limits. Do not include personal identifiers, unique device identifiers,
host-local paths, or raw captures that can contain flight or device data.
