# Semantic colors

Components use semantic color tokens. They do not select palette hues directly. Switch the theme
from the toolbar to inspect each token in light and dark mode.

Color does not communicate state by itself. Components also use text, icons, shape, or position to
make each state identifiable.

## Text and boundaries

Muted text is suitable for secondary content. Faint text is only for decorative glyphs and
separators. It is not suitable for labels.

## Status and alarm roles

Normal and caution states use tinted surfaces. Warning and danger states use solid surfaces. This
fill change makes the alarm escalation visible without relying only on hue.
