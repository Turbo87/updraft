# Typography

Updraft uses Barlow for interface text. It uses Barlow Semi Condensed for values that the pilot
reads as numbers. The condensed family keeps changing values compact without reducing their size.

Body text is at least 17 pixels. Captions use 15 pixels. The 14-pixel role is reserved for short,
uppercase section titles. Numeric values use tabular figures so that digits do not move when values
change.

## Numeric family

<div
  style={{
    fontFamily: 'var(--font-numeric)',
    fontSize: '2rem',
    fontWeight: 700,
    fontVariantNumeric: 'tabular-nums',
  }}
>
  {'0123456789 +1.8 248°'}
</div>

Numeric text uses weights 500, 600, and 700. Use `font-variant-numeric: tabular-nums` with every
numeric role.
