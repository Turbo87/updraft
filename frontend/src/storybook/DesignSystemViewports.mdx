# Viewports

The design system uses reference viewports for phone and tablet layouts. Select them from the
viewport toolbar when you compare a story with the design system.

## Galaxy S23

The phone reference viewport is 360 by 780 pixels. Use the rotate control to inspect its 780 by 360
pixel landscape orientation.

## iPad

The tablet reference viewport is 768 by 1024 pixels. Use the rotate control to inspect its 1024 by
768 pixel landscape orientation.

These dimensions are stable comparison frames. They are not minimum supported screen sizes.
